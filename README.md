# Ashmita Dutta

Computer science undergraduate in Kolkata, building user-centered, intelligent applications. I make responsive web apps and apply machine learning to real-world problems, with a focus on intuitive, accessible experiences that people can trust. I'm also working through a 135-day Java data-structures and algorithms challenge.

Trust is the thread, so I like problems where speed and safety pull against each other, such as banking flows and fraud-risk engines. I find bugs by running the whole system, then write regression tests so they stay fixed.

Completed the JPMorgan Chase Advanced Software Engineering virtual experience on Forage ([repo](https://github.com/ashmita13dutta/forage-midas)). Research intern at NITTTR Kolkata (2026), where I built FinTalk, an offline, multilingual voice finance assistant, and at Amity (2025), where I built a Neo4j knowledge graph for movie and song recommendations.

## Projects

**[Online Banking & Fraud Detection System](https://github.com/ashmita13dutta/online-banking-fraud-detection-system)** ([live demo](https://ashmita13dutta.github.io/online-banking-fraud-detection-system/))
Java 21, Spring Boot, React. Every transfer is scored by a deterministic rule engine before it settles: low-risk completes, medium-risk needs a verification code, high-risk waits for an analyst. Debit, credit and status change happen in one transaction, with an append-only audit trail.

**[Notes Tetris](https://github.com/ashmita13dutta/notes-tetris)** ([live demo](https://ashmita13dutta.github.io/notes-tetris/))
Plain JavaScript. Paste your notes and they are packed onto A4 pages like Tetris, using the biggest font that still fits, then printed or saved as a PDF. The packing is best-fit bin packing plus a binary search on font size, and it has unit tests.

**[Postmark](https://github.com/ashmita13dutta/postmark)** ([live demo](https://ashmita13dutta.github.io/postmark/)) (in progress)
React, Vite, Framer Motion. A journaling PWA where every day becomes a postage stamp. Offline-first, with all data kept on the device and postcards sealed until the 1st of the next month.

**[RentAFit](https://github.com/ashmita13dutta/RentAFit-Frontend)** ([live demo](https://ashmita13dutta.github.io/RentAFit-Frontend/))
React, Vite, Bootstrap. Front end for a clothing rental marketplace with renter and lender flows and a mock-first ML price, moderation and recommendation demo.

**[Sahayatri](https://github.com/ashmita13dutta/Sahayatri-Frontend)** ([live demo](https://ashmita13dutta.github.io/Sahayatri-Frontend/))
Bootstrap, Leaflet, OpenStreetMap. A front-end prototype for public transport: commuter route discovery on a map, and a driver app for crowd-level updates, running on mock data.

**[ParaPlan](https://github.com/ashmita13dutta/paraplan-landing)** ([live demo](https://ashmita13dutta.github.io/paraplan-landing/))
HTML, CSS, JavaScript. A responsive landing page for an invented SaaS for Kolkata's neighbourhood clubs, with a working chanda tracker demo, a pricing toggle and a validated form.

**[DSA-135](https://github.com/ashmita13dutta/DSA-135-)**
Java. A fixed 135-day curriculum (Aug 15 to Dec 27, 2026) with exercises, LeetCode solutions and notes. Only completed work is committed.

**[DMV_Lab](https://github.com/ashmita13dutta/DMV_Lab)**
Python. Data mining and visualization lab programs.

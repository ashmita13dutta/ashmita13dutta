## ⭐ Featured Projects

### 🏦 [Online Banking & Fraud Detection System](https://github.com/ashmita13dutta/online-banking-fraud-detection-system)
![Java](https://img.shields.io/badge/Java_21-ED8B00?style=flat-square&logo=openjdk&logoColor=white)
![Spring Boot](https://img.shields.io/badge/Spring_Boot_3.5-6DB33F?style=flat-square&logo=springboot&logoColor=white)
![React](https://img.shields.io/badge/React_19-20232A?style=flat-square&logo=react&logoColor=61DAFB)

A full-stack banking simulation with a **transparent, deterministic fraud-risk engine**. Every transfer is scored before it settles. Low-risk transfers complete instantly, medium-risk ones need a verification code, and high-risk ones wait for an analyst's decision. Debit, credit and status change run in a single database transaction, and every action lands in an append-only audit trail.

- 🔐 BCrypt + stateless JWT auth, beneficiaries, available-balance tracking, analyst case review
- ✅ CI pipeline, plus three real defects found and fixed with regression tests
- 🌐 **[Live demo](https://ashmita13dutta.github.io/online-banking-fraud-detection-system/)** (simulated data, no real money)

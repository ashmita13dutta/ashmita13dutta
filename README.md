### 🏦 Online Banking & Fraud Detection
<img src="https://skillicons.dev/icons?i=java,spring,react,vite&theme=dark" alt="stack" />

A full-stack banking simulation with a **transparent, rule-based fraud-risk engine**. Every transfer is scored *before* it settles:

- 🟢 **Low risk** → completes instantly
- 🟡 **Medium risk** → needs a verification code
- 🔴 **High risk** → held for an analyst's decision

Debit, credit and status change run in **one database transaction**, and every action goes to an append-only audit trail.
